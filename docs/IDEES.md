# Idées d'amélioration (par ordre d'impact pour la démo)
1. **Démo web** : téléverser/prendre une photo → résultat annoté (Livraison 2, API + page web).
2. **Vraies photos** : photographier une vraie carte imprimée + bandelettes sous 3-4 lumières ; recaler les seuils.
3. **Carte plus robuste** : mesurer les couleurs imprimées avec un scan ; ajouter un patch « blanc papier » dédié.
4. **ΔE2000** à la place de ΔE76 ; confiance calibrée statistiquement.
5. **Historique patient chiffré** (SQLite/SQLCipher) et export PDF du rapport (en cours d'action, mais pas totalement fait).
6. **Suivi dans le temps** (ex. protéinurie en grossesse) avec alerte de tendance.
7. **Multilingue** (français, anglais, langues locales) et mode vocal pour agents de santé.
8. **Mode hors ligne** : web app installable (PWA) ou application Flutter.
