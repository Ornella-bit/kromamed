# Tester KromaMed sur téléphone

## 1. Ouvrir l'application
1. Sur le téléphone, ouvrez Chrome (Android) ou Safari (iPhone) et allez à l'adresse Render du site
   (`https://kromamed-xxxx.onrender.com`). L'offre gratuite s'endort : le premier chargement peut prendre une minute.
2. Installer comme une application : Chrome → menu ⋮ → **Ajouter à l'écran d'accueil** (ou « Installer l'application »).
   Safari → bouton Partager → **Sur l'écran d'accueil**.

## 2. Vérifier le design (sans carte imprimée)
- Parcourez Accueil, Historique, Guide, Profil. Touchez une démo (« Infection urinaire probable ») puis **Enregistrer**.
- Notez tout ce qui est trop petit, coupé ou difficile à toucher : envoyez-moi une capture d'écran.

## 3. Vérifier la caméra
- Touchez le bouton rond vert, puis **Bandelette trempée : démarrer** (sans vraie bandelette pour ce test).
- Le navigateur demande l'accès à la caméra : **Autoriser**. L'image doit apparaître avec le cadre jaune.
- La caméra intégrée ne marche qu'en **https** (adresse Render). Sur un réseau local (`http://192…`), utilisez les boutons de
  gauche (galerie) et de droite (appareil photo du téléphone).

## 4. Réglage avec de vraies photos (quand la carte est imprimée)
1. **Profil → Paramètres → Photo de test (réglage)**.
2. Posez la carte imprimée à plat, lumière naturelle, et photographiez-la.
3. Le résultat affiche les 6 contrôles qualité en détail (repères, netteté, exposition, éclairage, lumière et contraste, bandelette) et les images
   vues par le moteur. En mode test, la **bandelette n'est pas exigée** : photographiez la carte seule. Faites une capture d'écran.
4. Répétez avec 3 lumières (fenêtre, ombre, lampe) et envoyez-moi les captures : je règle les seuils d'après vos résultats.

## Si quelque chose ne marche pas
- Écran blanc ou ancienne version : fermez l'application, rouvrez-la deux fois (la mise à jour se charge au 2e lancement).
- Caméra noire : vérifiez l'autorisation de la caméra dans les réglages du navigateur.
- L'analyse échoue : l'application a besoin d'Internet pour envoyer la photo au serveur (le mode 100 % hors ligne est prévu plus tard).
